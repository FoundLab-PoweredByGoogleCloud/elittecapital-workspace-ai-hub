# Resumo para Participantes — Treinamento NotebookLM Hub

Guia rápido (1 página) para impressão ou consulta:

1) Objetivo
- Gerar o relatório mensal em 15–30 min usando o Hub e o template.

2) Passos rápidos (checklist)
- Abrir `NotebookLM/Macro Weekly` → rodar prompt "Resumo executivo (5 bullets)" → copiar bullets
- Abrir `NotebookLM/Carteiras & Alocação` → carregar arquivo de carteira → rodar prompt → copiar tabela
- Abrir `03-reporting/relatorio-mensal-template.md` → colar conteúdo → revisar
- Salvar como `YYYY-MM-DD - <Cliente> - Relatorio Mensal - v01` em `Clients/<Cliente>/Reports/`

3) Prompts úteis (copiar/colar)
- "Resumo executivo (5 bullets) com foco em impactos na alocação." 
- "Analise o arquivo <nome> e resuma a alocação por classe..."

4) Se algo der errado
- Verifique quais fontes foram usadas (peça ao Notebook: "Quais fontes você usou?")
- Se faltar dados, anote e peça ao owner da fonte para atualizar
- Contato: POC Elitte — [nome/email]

5) Boas práticas
- Não misture fontes de clientes
- Sempre usar prompts aprovados do `prompt-pack-ptbr.md`
- Registre a versão das fontes usadas no README do notebook
