# Catálogo de Notebooks

Este diretório contém os notebooks padronizados do Hub.

Notebooks incluídos:
- `macro-weekly.md` — Macro Weekly
- `carteiras-alocacao.md` — Carteiras & Alocação
- `suitability-perfis.md` — Suitability & Perfis
- `compliance-politicas.md` — Compliance & Políticas
- `comercial-qa.md` — Comercial / Q&A

Cada notebook tem um README com finalidade, fontes "golden" e prompts recomendados. Para adicionar um novo notebook, basta criar um arquivo `.md` com a mesma estrutura e apontar as fontes.
