# DNS Records (Checklist)

## Objetivo
Garantir que o domínio e o e-mail estejam configurados de forma mínima e segura.

## Checklist
- [ ] Acesso ao provedor DNS do domínio
- [ ] Registros do Google Workspace aplicados (ver console de admin)
- [ ] SPF configurado (mínimo viável)
- [ ] DKIM configurado (recomendado)
- [ ] DMARC configurado (mínimo viável)

> Observação: valores exatos dependem do console do Google Workspace.
