# Automação — Scaffold (EC-JAN-FAST)

Objetivo: exemplos simples que podem ser usados por um admin para automatizar criação de grupos, usuários e Shared Drives. Estes scripts são *exemplos*; exigem configuração de credenciais e revisão de segurança antes de uso em produção.

Arquivos incluídos:
- `gam/` — comandos GAM para criar usuários e grupos
- `gcloud/` — comandos para habilitar APIs e criar service accounts
- `terraform/` — exemplo de recursos (módulo inicial apenas)

---

Atenção: os scripts contém placeholders (EXAMPLE) que precisam ser adaptados ao ambiente da Elitte. Se quiser, eu adapto os scripts com os nomes reais de grupos/usuários após receber os e-mails finais.
