# assets/

Coloque aqui os arquivos de identidade visual usados pelo repositório e pelos documentos.

Nomes recomendados:
- `elitte-logo.svg` — logo principal (SVG preferível)
- `necton-logo.svg` — logo parceiro (opcional)
- `foundlab-badge.svg` — badge/label da FoundLab
- `google-cloud-partner.svg` — badge Google Cloud Partner (substituição por PNG/SVG oficial é possível)

Observações:
- GitHub renderiza SVGs diretamente em READMEs quando referenciados com `![alt](assets/elitte-logo.svg)` ou com HTML `<img src="assets/elitte-logo.svg">`.
- Não comite versões com informações sensíveis (chaves, PDFs com dados privados).

Se você me enviar o arquivo SVG, eu adiciono aqui e atualizo os READMEs para usá-lo nas docs automaticamente.
