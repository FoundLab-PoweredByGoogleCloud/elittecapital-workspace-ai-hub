# Como exportar o Relatório para PDF (instruções para não técnicos)

Arquivo preparado: `2025-12-28 - EXAMPLE - Relatorio Mensal - v01.html`

Passo a passo simples (Windows / Mac):

1. Abra a pasta `Clients/EXAMPLE/Reports/` e dê um duplo clique no arquivo `2025-12-28 - EXAMPLE - Relatorio Mensal - v01.html` — ele abrirá no seu navegador (Chrome/Edge/Safari).
2. No navegador, pressione Ctrl+P (Windows) ou Cmd+P (Mac) para abrir a janela de impressão.
3. Em "Destino"/"Impressora", escolha **Salvar como PDF** (ou "Microsoft Print to PDF" no Windows).
4. Ajustes recomendados:
   - Layout: Portrait (vertical)
   - Margens: Padrão
   - Marcar a opção **Imprimir planos de fundo** (ou "Background graphics") para preservar as cores e logo
   - Escala: 100%
5. Clique em "Salvar" e escolha o local: `Clients/EXAMPLE/Reports/` e nomeie como `2025-12-28 - EXAMPLE - Relatorio Mensal - v01.pdf`.

Observações:
- Se preferir, abra o HTML no Google Chrome, clique em "Enviar" e escolha "Salvar como PDF" para um resultado idêntico.
- Se quiser que eu gere o PDF diretamente e adicione ao repositório, eu preciso que permita o upload do arquivo gerado ou que eu tenha acesso a uma ferramenta que gere o PDF no ambiente (posso também gerar localmente e fornecer o arquivo se você autorizar um upload).
